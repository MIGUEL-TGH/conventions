# conventions

Original de [`CONVENTIONS-GENERAL.md`](CONVENTIONS-GENERAL.md), la convención de desarrollo
que aplica a todos los proyectos (frontend Vue y backend PHP).

## Cómo se usa

- **Sólo aquí se edita.** Cada proyecto lleva una copia idéntica en su raíz; las copias se
  reemplazan completas, nunca se editan.
- **Cada cambio sube la versión** (mayor, menor o parche) que aparece en el encabezado del
  documento y agrega una línea a su historial. Ver "Cómo se usa este documento".
- **Una copia está al día** si su versión coincide con la de este repositorio.
- Mensajes de commit según Conventional Commits (§11): `docs: versión 2.1.0 — reglas de tests`.
